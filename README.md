# odin-recipes

Odin recipes is the first task of The Odin Project which is about creating a website which lists recipes of certain dishes

This particular project involves recipes of 3 of my favorits dishes

- Samosa
- Pani Puri
- Kalakand

Skills implementd in this project

- ordered lists
- unordered lists
- images and links
- directory structuring
- relative paths
